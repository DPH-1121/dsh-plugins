# dsh-plugins

DeepSeek Harness 的插件搜集面板：每 6 小时从 GitHub 采集一次 DSH 插件项目，收进一份索引，在侧栏面板里本地搜索，一键复制 `github:owner/repo` 去官方客户端安装。

只做搜集与展示 —— 安装、卸载、体检都交给 DSH 官方客户端。

## 安装

见 [**DSH 插件安装教程**](./docs/install.md)。

## 其他 DSH 插件

- [dsh-opencode-go-plus](https://github.com/DPH-1121/dsh-opencode-go-plus) —— 在 DSH 里使用 OpenCode Go 订阅模型，自动适配网关新模型并显示套餐额度。
- [dsh-provider-plus](https://github.com/DPH-1121/dsh-provider-plus) —— 自定义模型提供商工作台：图片输入、网关请求头、模型拉取、连通性测试、用量查询。
- [dsh-wallhaven-wallpaper](https://github.com/DPH-1121/dsh-wallhaven-wallpaper) —— 在设置里搜 wallhaven，把图片铺成 Web GUI 背景。
